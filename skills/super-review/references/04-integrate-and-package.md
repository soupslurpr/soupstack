# Phase 4: Integrate and package

Integrate the broad review and later assessments into one report on {{TARGET}}. Preserve supported findings, negative results, evidence levels, known or previously reported status, and material gaps. The security assessment is part of the full review, not a replacement for it. Reconcile the current user request and revisions, including requested questions and tests. Group supported findings by evidenced origin where meaningful (for example, target-specific, inherited or upstream, and mixed or uncertain); do not guess an origin. Label local or unreleased changes separately.

Create one tidy ZIP in {{OUTPUT_DIR}} when the user requests a package or issue bundles or other evidence artifacts need a consolidated handoff. When a ZIP is warranted, include the main report, a concise index, and one folder per supported finding, grouped by origin where applicable. Put each finding's reproduction or evidence beside its write-up; incorporate directory bundles and extract any individual ZIPs into those folders instead of nesting ZIPs by default. Otherwise return the report and artifact paths. Include unresolved leads only if requested and clearly separate them from supported findings. Distinguish reproducible bundles from evidence-only material; do not label an untested lead as a reproduction.

For every issue bundle and any consolidated ZIP, verify the delivered copy: extract ZIPs before checking, and inspect directory bundles as delivered. Check inventory, integrity, provenance, report navigation, source references, reproduction instructions under their stated prerequisites, and material resource-restoration claims. Use revision-anchored, repository-relative or packaged source references; remove broken host-specific or disposable-build paths. Check handoff artifacts for identifiers that create privacy or portability problems. Omit irrelevant values; use consistent pseudonyms or portable references where values still need to be correlated. If no safe representation preserves the evidence, limit what is shared and explain the gap. Preserve originals subject to applicable access and retention limits, and describe material changes to handoff copies. If {{OUTPUT_DIR}} is disposable, move retained artifacts to an established durable location and verify them there.

Obtain an independent challenge of the exact final report, its coverage, and any standalone or packaged evidence artifacts; address consequential objections. If material corrections follow, obtain a fresh, focused independent check of the exact final deliverables before handoff. Return the report and artifact paths, any ZIP paths and checksums, resource state, and outstanding limits. Deliver externally only as the current user instructions authorize.
