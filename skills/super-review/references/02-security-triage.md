# Phase 2: Assess the first report

Review {{PHASE1_REPORT}} against the underlying evidence and target. Determine which observations have security significance, what behavior and impact are supported, and which claims remain unverified. Follow the security review guidance and triage criteria supplied with this phase. Challenge consequential claims with independent examination and relevant counterevidence; use authorized validation when it resolves a material uncertainty.

For each issue with demonstrated, repeatable impact, prepare a self-contained reproducible issue bundle under {{OUTPUT_DIR}}/bundles with a minimal reproduction, prerequisites, expected and observed results, supporting evidence, and limits. Keep it as a directory unless the user requests an individual ZIP or a separate archive is needed for handoff. Keep source-only or inconclusive leads distinct; a bundle without reproduction must be labeled as evidence only. Produce {{OUTPUT_DIR}}/phase-2-report.md with dispositions, provenance, bundle paths, and outstanding validation. Return the report and resource state. Do not call the phase complete while a consequential claim or requested check remains unaddressed.
